Every game has a first minute, and most players decide in it whether to stay. A strategy game has a harder first minute than most, because it has things to teach: how a turn works, what the map means, what winning looks like. The question is how to teach them without making a break feel like a classroom.

Our answer for [Iltonggi](https://iltonggi.ipe.rest) is to make the first round smaller than the rest.

## Small on purpose

Iltonggi's rounds are meant to finish in 5 to 10 minutes. The first game is kept short at 20 turns. And in the first two rounds the enemy will not attack. That is how we described the plan on the game's blog. The reason is simple. We wanted to give people time to get used to the rules before anyone pressed on them.

This is a different idea from a tutorial. A tutorial stops the game to explain it. A gentle first round lets you play the real game with the sharpest edges taken off, so what you learn, you learn by doing something.

## What a welcome should and should not do

We have a short list for ourselves.

It should end. A first session with no visible finish line is a poor welcome, so the first round is short enough that you can see the end from the beginning.

It should not lie about the game. A softened opening is useful only if the next round does not feel like a different game. The enemy sits still at first, then the rest of the game begins. We would rather you notice that change than not.

It should not nag. A welcome is not a request to return tomorrow. Iltonggi aims to save automatically, so closing it at any moment costs you nothing, and if you leave for the menu mid-round, a message tells you it was saved. When someone comes back after a while away, the game simply lets them know, briefly, that their game is still where they left it.

## A choice at the start

At the start you also choose a kingdom and a difficulty. We think that matters too. A player who picks the difficulty has already made a first small decision about the kind of break they want, and the first round does not have to guess.

## The honest part

All of this is intent, and Iltonggi is not released. It is being tested on TestFlight, and the iPhone version comes first. A gentle opening can still be too gentle, or not gentle enough, and we will not know until real players have been through it. If it turns out wrong, we would rather say so on the blog than quietly change the number.
